# 一致性锚定机制（角色 / 服装 / 道具 / 场景 / 色调）

> 建 02_锚定表时读本文件。原理：**参考图 > 文字锚定 > 无锚定**，双保险 = 锚定短语逐字复用（文字层）+ 参考图多图输入（图像层）。

### 场景锚定（每个场景）
| 字段 | 说明 |
| --- | --- |
| 场景描述锚 | {空间结构/主要道具/材质}固定文字 |
| **场景母版（多画面场景必写）** | 场景母版 ID（SC01）+ **四向锚**：以画面为参照系，左/右/中央/远后方各登记一个固定物（"左侧固定为翻倒燃烧公交车，右侧固定为燃烧广告牌，中央固定为破损隔离带，远后方固定为破碎高楼与高架桥"）——跨画面空间感靠方向+固定物，不靠复述全场景 |
| 光线锚 | {时段+方向+色温}；多光源场景登记编号光源表（L01/L02/L03=来源+方向+色温K+强度%+硬软+动态行为+落点，写法见 cinema-grade-params.md） |
| LOCATION MAP | 多角色场景必写：各角色/关键道具的固定位置、朝向、相互距离（防跨画面瞬移）；单角色场景可省。**距离常数**：关键空间关系写死成常数并逐画面复述——对峙距离（"两人相距十步约六米"，一步≈0.6米）/追逐距离（"前后相距八步约五米"）/贴身距离（"不到半臂"）——实测教训：不写死，模型每张画面自取距离，用户连改三次；情景图提示词必须复述该画面适用的距离常数 |
| 参考图路径 | 场景参考图；用于 ≥3 张画面或需多机位素材 → 四视图全套（母版/对向回望/45°斜角/垂直俯拍，见 extended-views.md）全部登记 |

### 空间布局登记（情景图站位的地基——防"每张画面长出一个新世界"）

1. **从场景图认家具，不从提示词认**：场景参考图生成后，从**图里实际可见**的物件中登记 4-20 件能站/能坐/能倚的东西——提示词里写了但图上没有的家具**不许用于站位**（实测事故：让人坐在图上不存在的高台，每张画面模型各自发明一个高台，张张不一样）
2. **每人一条走位记录**：在哪件东西的哪一侧 + 沿该侧多远 + 坐/站/倚 + 八方位朝向（面朝北/面朝门口）。位置写"哪一侧"，**不写坐标**（语义绑定第一层：模型没有坐标系）
3. **站位句由记录生成**，一句自然语言（"沈知微站在岸端土坡上面朝北，林枫坐在渡口条凳东端；其余座位空着，没有其他人"）——情景图提示词的主体位置槽照抄
4. **群演默认 0**：剧本没写有别人，走位句就显式写"没有其他人/其余座位空着"——不写这句，模型会把空位画成有脸的陌生人（背景围观群众是最常见的画面污染）。**边界**："默认 0"只排除**未被剧本/用户授权**的背景人物；用户或剧本显式要求出场的角色（哪怕"剧本没写但他必须出现"）计入在场声明——走位句写法："除了她与柱子另一侧的{授权角色}，再没有其他人"
5. **同场景成套画面不挪位**：无叙事驱动的系列画面，人物位置不变，只允许改朝向/坐站——每次重新生成都是重新掷骰子，位置不动骰子就少掷一次

### 道具锚定（每个命中判定规则的道具）

**哪些道具入本节**：命中六条判定规则任一即入表——判定全文见 **prompt-rules.md 一节·骨架 0（角色视觉锚定资产）的道具判定规则**（唯一的家）。要点：跨画面出现、触碰变状态、会位移、剧情承载、画面要对焦、角色强关联随身物。

| 字段 | 说明 |
| --- | --- |
| 道具锚定短语 | {名称/材质/颜色（含十六进制色号）/尺寸/磨损痕迹/标志性细节}固定文字，逐字冻结 |
| 状态清单 | 该道具在剧中出现的所有状态（收起/打开、旋紧/旋开、完整/破碎）——**每个状态一张参考图**；**可分离组合道具每部分单独一张**（拆分理由与画法见 prompt-rules.md 一节·骨架 0）；状态间**互参声明**（"破碎态=完整态被击碎的碎片，同一物件"） |
| **持械手/鞘位** | 武器类必填三要素：**持械手**（右手持刀/已脱手）+ **鞘位**（空鞘挂左腰侧/收入背后）+ **双手占用**（另一只手空着/抓着桥栏）——同一道具同一时刻只有一个状态（防"腰间入鞘+手中出鞘并存"），转换过程显式写（"从腰间鞘中拔出，鞘留在腰上"）。**无鞘武器（骨矛/短棍/石斧）写"无鞘"，另填收纳位**（靠墙/挂腰/随身/斜靠石台），不虚构一个鞘 |
| 参考图路径 | assets/{道具名}_{状态}.png（白底道具图，配方见 prompt-rules.md 骨架 0d）；**图案类道具**用图案特写锚定图（纯色底、图案占画面 70%+、平铺无透视变形） |
| 连续性规则 | 该道具跨画面/跨批次的状态延续说明（"沿用上一条已在桌上的那枚银锭，不重新变出新的"） |
| 链接画面 | 该道具入画的画面编号——03 对应情景图的参考图组配必须链接其参考图（防"道具在画面里凭空变了样子"） |

### 风格圣经（全局唯一）
从 styles.md 选定后逐字冻结，追加到每条图片提示词末尾。

**多世界/双场景项目的词条适配（逐字冻结的唯一例外通道）**：全片含语义差异极大的多个世界（现实站台 vs 回忆院子）时，某条风格词条在另一世界语义不成立（"霓虹倒影"进夏夜院子）——处理规则：①冻结时即登记**场景变体**（02 风格圣经节按场景分列变体词条，如"院子世界：檐下灯泡的微弱暖光在湿石板上拉出短倒影"——保持同一视觉语法关系、替换载体物）②每条提示词只逐字使用**所属世界的变体**，不硬塞不成立的词条 ③变体登记后同等冻结，中途不改；未登记变体而自行改词 = 违反逐字规则。单世界项目不适用本节，仍全片一条圣经。

### 色彩基调（全局唯一，十六进制色板——先于生成任何场景图定）

| 字段 | 面积 | 说明 |
| --- | --- | --- |
| 环境底色 | 约 60% | 空间主色（墙面/天空/地面），定调 |
| 中间调 | 约 25% | 家具/服装/道具主色 |
| 点缀色 | 约 10% | **只给特定物体**（打火机/花/招牌），不铺满 |
| 肤色基准 | — | 人物皮肤；冷环境里保留血色才真实 |
| 暗部色 | — | 阴影带色相，不是纯黑 |

进图片提示词色调槽的形式 = **色号 + 颜色落在哪里**（不只列色号，更不写"暖色调/低饱和"倾向词）。选定后与风格圣经同等逐字冻结；成套画面色调一致靠色板锚定。推荐色板见 styles.md 色彩基调节。

## 二、锚定短语写作规则

**锁定优先级三级链（冲突时的裁决顺序）**：`USER-LOCKED > 参考图/风格提取的既定裁决 > 系统默认补全`
- **USER-LOCKED**：用户在 GATE0/GATE1 显式选择或修改过的项（锚定短语/色板/风格/风格与色板的选择）——**永不被系统覆盖**，要改必须回到对应 GATE 重新确认
- **OPEN**：skill 按主题补全的默认值——可被用户参考图的迁移裁决填充，也可被用户随时改
- 02 锚定表各字段默认视为 USER-LOCKED（因为经过 GATE1 确认）；GATE1 之前的草稿期标 OPEN
- 候选写进提示词 ≠ 用户已接受——GATE1 呈现过的才是接受

1. **具体到可指认**：`28岁女性，齐肩黑色短发微卷，左眉角一颗小痣，米白色针织衫配浅灰阔腿裤，清瘦`✓；`一个年轻女性`✗
2. **顺序固定**：年龄性别→体型脸型→发型发色→五官特征→服饰→配饰。跨画面复用时顺序不变
3. **7-9 个视觉要素**：太少不够锚定，太多稀释重点
4. **道具同理**：材质/颜色/尺寸/磨损逐项具体，`一把长柄黑伞，伞面有轻微使用褶皱，木质伞柄`✓
5. **着装状态逐部位列明"有/无"（V2.9——实测教训：锚定写"上身无衣物"，生成时模型仍给角色加了肩带披挂）**：单一否定句锁不住着装——模型对"无衣物"的先验会自动补配饰/遮挡物。角色处于非常规着装状态（裸露/半裸/破损/泳装/盔甲卸下）时，锚定短语与受影响画面的提示词必须**逐部位列有/无**：`肩带无/披挂无/护臂无/腰带无/腰间兽皮裙有/腕部藤蔓环扣有`——与 02 锚定表逐字对齐，跨画面逐字复用。常规着装（完整现代/古代服饰）不需要此清单，写全服饰要素即可

## 三、跨资产一致性操作规则（图片端多图参考）

### 图片端（多图参考）
- **参考图六条硬标准 + 数量上限**：全文见 **prompt-rules.md 0.4 节**（唯一的家）。本处只留判定要点——一张图只回答一个问题，脸和身子分开，3-5 张最优 ≤8（超 10=噪声），禁九宫格拼贴设定卡
- **角色资产 = 三层分工**（AI 只识别像素/轮廓/五官比例，不读图中文字）：视觉锚定层（三视图主锚+面部特写+按需补充锚）/ 文字规则层（锚定短语进提示词）/ 人工参考层（拼贴卡自看，绝不整卡上传）
- **头身分离必须落到出图动作上**（实测教训：规则写了，实际生成时没分开——一张图同时画全身和脸，脸只占两三成，一致性当场失效）：03 的人物参考图节**按 templates 0a/0b 分两张出图**——0a 白底三视图（只管比例/服装/轮廓，脸裁掉或转过去）+ 0b 面部特写（脸占画面 6 成以上）。**不许合成一张"设定图"交差**
- **互挂参考（人物↔场景↔情景三向引用）**：三类资产不是各自孤立出图，而是相互挂参考——
  - **情景图必挂**：该画面的角色锚定图（三视图+近景加面部特写）**＋** 所在场景图（母版）→ 人物与空间同时锁住
  - **场景图可挂**：已有定稿场景图作母版基准（同场景异状态/异机位时）；道具入画的场景挂道具图防串戏（prompt-rules 0.5）
  - **人物图之间**：同角色多状态图互为参考（服装改版时挂上一版防漂回旧设定）；角色同框时挂各自锚定图，**受"一张图一张脸"限制——合成图仅作身形/服装参考，脸另给特写**
  - 每张挂入的图写**双向作用域声明**（锁什么+不锁什么），角色路由规则见 prompt-rules 一节
- **基准参考法（同场景异状态画面的有效手段）**：一张已定稿的成图可作为后续画面的**基准参考**——同场景不同状态（"A31 定场全景作 S3d 动作情景基准"）、同场景异机位、同角色异动作。做法：基准图挂入该画面的参考图组并声明"只锁空间布局/光线方向/主体比例，不锁姿势与表情"。**价值**：省去重新描述整个场景，且空间关系天然一致。与"定稿标记"配套（防基准图被重生成污染）
- **参考图按画面机位动态组配**：正面画面 → 三视图（或裁出正面图）+ 场景图；侧/背画面 → 必须加对应视图；特写/近景 → 必须加面部特写锚定图；**道具入画的画面 → 加道具对应状态图**
- **参考图角色路由（每张图只有一个权威维度）**：常见权威维度=角色身份/服装/道具/场景空间/构图/光线/色彩/材质/风格语法；**显式排除收窄角色**（"只参考灯光不参考构图"→ 排除句写进用途声明）；多参考图矛盾时按维度分工各取所长，**禁止"综合一下"**（平均=谁也不是）；**风格参考图的迁移范围三档**：强继承（色彩结构/材质处理/媒介质感/曝光行为）→ 条件继承（机位/构图/尺度/光向，逐项标 Preserve/Adapt/Release）→ 默认不迁移（人物身份/服装/道具/文字/品牌）。提取方法见 styles.md 风格提取（解梦卡）
- **绝不"编辑已生成的图"来换场景/姿势**——每次编辑累积伪影
- 多人场景：宁可拆图（每画面 ≤2 人同框为佳）
- 长会话（12+ 张）后参考图"失忆"——分批新开会话/独立请求，每次重传参考图
- **资产引用矩阵先行**（03 文件头）：零引用资产不生成，防浪费

### 色调端
- 图片端：风格圣经**全量**逐字后缀 + **色彩基调色板**（十六进制色号+颜色落在哪里）进色调槽

## 四、失效传播

锚定表（02）变更时：
1. 在 03 文件头部插入标记：`> ⚠ 上游锚定已变更（变更日期），本文件待重新生成`
2. 聊天中明确告知用户哪些文件失效、需要重做哪些提示词
3. 未重新生成前，旧提示词与新锚定混用 = 一致性必然崩坏
- 02 变更同时回读所有引用该锚定的情景图提示词（改一资产回读全部引用——SKILL.md 单点修改复查纪律）
