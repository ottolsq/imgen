# 成品范例库（Exemplars）

> 写**角色全身设定提示词**时读本文件。范例来自用户实测：提示词原文 + 出图效果好 + 产出图喂 AI 当参考效果可接受——三者齐备才入本库。范例是"九段结构"的实例（结构规则全文见 prompt-rules.md 骨架 0·全身角色描述九段结构，唯一的家）；本文件存**范例全文与逐段批注**，不复制结构规则本身。

## 入库纪律

1. **未实测不标优**：范例入库三条件——提示词原文可得 + 用户确认出图效果 + 用户确认用途（喂 AI 参考效果可接受 / 展示级）。三者缺一登记为"待验证"
2. 登记来源与日期；用户给的范例标注 `[用户实测]`
3. 范例不逐字复用到新角色——学习的是结构段与技法，内容每次按新角色重写
4. 批注对照九段结构编号（①比例体型 → ⑨色彩总纲）

## 读取策略升级阈值（防库变厚后全量读浪费）

- 本文件被命中时**全文件读取**（一次会话最多一次，读取纪律见 SKILL.md）——当前规模（<500 行）这是正确行为，不做更细的切分
- **>500 行**：文件头加"按资产类型分节索引"（角色/服装/场景/道具），命中哪类只读哪节
- **>1000 行或单类 >10 条**：按类型拆文件（character-exemplars / scene-exemplars…），knowledge-index 路由表同步拆分
- 升级动作属于 skill 维护，在用户供样登记时顺手评估触发与否，不为此单独开工

## E1 · 成熟比例蓝色鲸鱼娘（动漫设定卡，单图整合视图）`[用户实测]`

> 来源：用户提供，2026-11-09。出图效果好；产出图喂 AI 当参考效果可接受。与 E2 构成**比例变体 DNA 对**（E2 批注节展开）。

### 范例全文

成熟比例的蓝色鲸鱼娘，身形修长，腰线清晰，腿部比例较长，头身比例接近成年女性角色。头发浓密，长度延伸到腰臀以下，发根是深海蓝，发束中穿插钴蓝色光泽，越靠近发尾越转为明亮的海蓝与浅青蓝；长发从两肩向外铺开，末端形成层层波浪卷。额前是轻覆额头的侧分斜刘海，脸颊旁留着向内弯曲的短发，头顶一根细长呆毛自然向上弯起；后脑上层头发编成一圈细辫，并在垂落长发之间系上蓝色蝴蝶结。面部轮廓纤细柔和，眼睛呈明亮的杏仁形，深蓝外圈包裹渐变至亮蓝的虹膜，点缀清晰的浅色高光；神情开朗亲切，双眼有神、眼尾自然舒展，嘴角扬起轻松真诚的笑容，脸颊带淡淡红晕。头顶佩戴白色层叠蕾丝女仆发箍，两侧各有亮蓝色小蝴蝶结；头侧伸出一对横向舒展的深蓝色鲸鱼鳍状耳朵，鳍的内侧衬着白色波浪褶边。身穿深蓝与白色的精致女仆服，白色立领下系深蓝领结，领结中央镶有椭圆形蓝宝石和细金边。胸前是带纵向褶裥、纽扣和蕾丝边的白色布料，两肩有白色荷叶边肩饰；深蓝色袖子微微蓬起，袖口收紧并露出白色花边。腰间是贴合身形的深蓝色腰封，前面排列两行小巧的金色纽扣。深蓝色裙摆从腰部自然展开，长度落在小腿中段，较原先短裙更长一些，线条优雅、垂坠适度；裙摆叠有层次分明的白色荷叶边与蕾丝，裙面点缀细小金色十字星和精致装饰线。正面系白色围裙，下缘呈柔和波浪形并镶有花边，靠近裙角处印有蓝色小鲸鱼图案；背后系宽大的白色蝴蝶结，缎带顺着裙摆垂落。腰后伸出深海蓝色鲸尾，略带柔和光泽，向外下方延伸，末端展开为两片宽大的尾鳍，鳍缘渐变成浅蓝色。双腿穿白色过膝长袜，袜口饰有蕾丝和深蓝小蝴蝶结；脚穿深蓝色圆头玛丽珍鞋，脚背横带配金色圆扣，鞋跟为稳重方形中跟。角色设定图统一展示正面、侧面与背面全身视图，并辅以面部、发饰、裙摆和鲸尾细节；三视图保持同一套服装结构、配色与角色特征。整体以深海蓝、钴蓝、浅青蓝和白色为主，宝石蓝与少量金色用于精细装饰。

### 逐段批注（对照九段结构）

| 段 | 技法 | 范例落点 |
| --- | --- | --- |
| ① 比例体型 | **先验锚**：比例不写抽象数字，锚到模型已知概念 | "头身比例接近成年女性角色"——六个字接通"成年女性"先验包 |
| ② 头发 | **渐变三停靠**：发根/发束/发尾三站各写色名，不写"蓝色渐变"；四区各写（刘海/颊侧/呆毛/后脑辫+饰）+ 长度锚到身体（"延伸到腰臀以下"）+ 末端形态 | "发根是深海蓝，发束中穿插钴蓝色光泽，越靠近发尾越转为明亮的海蓝与浅青蓝" |
| ③ 面部 | 轮廓→眼→神态三步；眼写四件（形状+外圈色+虹膜渐变+高光）；**神态物理化**：不写情绪名词，写肌肉与气色 | "眼睛呈明亮的杏仁形，深蓝外圈包裹渐变至亮蓝的虹膜，点缀清晰的浅色高光；眼尾自然舒展，嘴角扬起轻松真诚的笑容，脸颊带淡淡红晕" |
| ④ 头饰+头部异形 | 逐件：位置+结构+颜色；**对称件显式计数**（"两侧各有"） | "发箍两侧各有亮蓝色小蝴蝶结"；鲸鳍耳：位置（头侧伸出）+方向（横向舒展）+**分面分色**（外侧深蓝/内侧白褶边） |
| ⑤ 服装 | **内外层分开写**（外层女仆服/内层褶裥胸布/围裙独立件）；每件四要素：位置+颜色+材质结构+装饰；**裙长锚身体**（"落在小腿中段"），不写"中长裙"这类模糊词 | "白色立领下系深蓝领结，领结中央镶有椭圆形蓝宝石和细金边" |
| ⑥ 躯体异形 | **四件套**：位置→方向→分面分色→末端渐变 | 鲸尾："腰后伸出（位置），向外下方延伸（方向），略带柔和光泽（表面），末端两片宽大尾鳍（末端），鳍缘渐变成浅蓝色（渐变）" |
| ⑦ 腿脚鞋袜 | 上到下：袜（长度+袜口装饰）→鞋（款式+横带+扣+跟型） | "白色过膝长袜，袜口饰有蕾丝和深蓝小蝴蝶结；深蓝色圆头玛丽珍鞋，脚背横带配金色圆扣，鞋跟为稳重方形中跟" |
| ⑧ 视图声明 | 单图整合：正侧背全身 + 细节点名 + 一致性句 | "统一展示正面、侧面与背面全身视图，并辅以面部、发饰、裙摆和鲸尾细节；三视图保持同一套服装结构、配色与角色特征" |
| ⑨ 色彩总纲 | 主色枚举+点缀色+**密度明示**（"少量""精细装饰"） | "整体以深海蓝、钴蓝、浅青蓝和白色为主，宝石蓝与少量金色用于精细装饰" |

**词汇族纪律示范**：全文形容词族统一"修长/纤细/清晰/优雅/垂坠/稳重"——与"成熟比例"同一气质；无一词从 Q 版词汇族（圆润/厚实/柔软）串入。

## E2 · Q版三头身蓝色鲸鱼娘 `[用户实测]`

> 来源与条件同 E1。与 E1 同一角色的比例变体——**比例变体 DNA 对**示范。

### 范例全文

Q 版蓝色鲸鱼娘，大头小身材，约三头身的圆润比例，头部、蓬松的长发和向外展开的裙摆构成柔软饱满的轮廓。头发以深海蓝为主色，从发根的深蓝逐渐过渡到发尾明亮的海蓝与浅青蓝；额前是层叠的斜刘海，几束短发贴着圆脸向内弯，头顶翘起一根弧形呆毛。后发浓密而修长，从肩背两侧垂下，末端散成一缕缕轻微卷曲的波浪发束。脸颊圆润，眼睛占脸部很大比例，双颊透出淡粉色，鼻子小巧，嘴巴小而精致；眼睛深蓝外圈包着亮蓝虹膜，瞳孔中有大小不同的白色与浅蓝色高光。头上戴着拱起的白色蕾丝女仆发箍，褶边层层叠叠；发箍两侧各系一枚亮蓝色小蝴蝶结。头侧有一对向两边展开的鲸鱼鳍状耳朵，外侧为深海蓝，内缘带白色波浪形褶边。身后伸出一条厚实的深蓝色鲸尾，从腰后向侧面弯起，末端分成两片圆润的尾鳍，下侧颜色渐浅并带一点蓝紫色。身穿深蓝与白色相间的女仆裙：内层白色高领衬衫有细密的纵向褶裥和深色纽扣，领口系深蓝蝴蝶结，中央是一颗金边镶嵌的椭圆蓝宝石；外层深蓝短上衣收在腰间，袖子蓬起，袖口露出白色蕾丝。腰前围着宽大的白色围裙，边缘是一圈细密荷叶边，正中印有小蓝鲸与水花图案。深蓝短裙向外撑开，裙摆下叠着多层白色花边；裙面和袖口点缀细小的金色十字星、针脚与浅金色蝴蝶结。腿上穿白色花边短袜，脚上是圆头深蓝色玛丽珍鞋，鞋面各有一枚浅金色小蝴蝶结。整体配色围绕深海蓝、钴蓝、浅海蓝与白色展开，以少量金色装饰勾勒细节。
